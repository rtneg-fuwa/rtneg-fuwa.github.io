このアプリについて

「ball-stream chat」は、YouTubeチャンネル「ボールの池 Ball Pond」の運営者自身が、自分のチャンネルのライブ配信を運営するために使う個人用アプリです。

アクセスする情報

このアプリは YouTube Data API を通じて、運営者自身のYouTubeアカウントに対してのみ動作します。具体的には、ライブ配信枠の作成と管理、自分の配信のライブチャットおよびチャンネル登録情報の読み取りを行います。

情報の利用と共有

取得した情報は配信の運営のためだけに使います。第三者への販売・提供はしません。ライブチャットの内容は、配信の演出（コメントでボールが落ちる仕組み）のためにリアルタイムで処理されます。

このアプリによる Google ユーザーデータの利用は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

English summary

"ball-stream chat" is a personal app used solely by the operator of the YouTube channel "Ball Pond" to run live streams on the operator's own account. Through the YouTube Data API it creates and manages live broadcasts, and reads live chat and subscriber information of the operator's own streams. Data is used only to operate the streams; it is never sold or shared with third parties. The app's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Contact: rtneg.fuwa@gmail.com
